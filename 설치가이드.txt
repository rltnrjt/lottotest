# 로또픽 — 설치 및 배포 가이드

## 📱 핸드폰 앱으로 설치하는 방법

### ① iPhone (Safari)
1. Safari에서 앱 주소를 열어요
2. 하단 공유 버튼(□↑)을 누르세요
3. "홈 화면에 추가" 를 누르세요
4. "추가" 를 누르면 완료! 앱 아이콘이 생겨요

### ② Android (Chrome)
1. Chrome에서 앱 주소를 열어요
2. 주소창 오른쪽 ⋮ 메뉴를 누르세요
3. "앱 설치" 또는 "홈 화면에 추가" 를 누르세요
4. 앱 아이콘이 바탕화면에 생겨요

## 🌐 무료로 인터넷에 올리는 방법

### 방법 1: Netlify Drop (가장 쉬움, 무료)
1. https://app.netlify.com/drop 에 접속
2. 이 폴더 전체를 드래그 앤 드롭
3. 자동으로 주소가 생성됩니다! (예: https://abc123.netlify.app)

### 방법 2: GitHub Pages (무료)
1. https://github.com 에 가입
2. 새 저장소(Repository) 생성
3. 파일들을 업로드
4. Settings → Pages → Branch: main → Save
5. https://[내아이디].github.io/[저장소이름] 으로 접속 가능

### 방법 3: Vercel (무료)
1. https://vercel.com 에 접속
2. GitHub와 연동 후 배포

## 📁 파일 구성
- index.html  ← 메인 앱 파일
- manifest.json  ← PWA 설정 (앱 이름, 아이콘 등)
- sw.js  ← 오프라인 캐시 (인터넷 없어도 동작)
- icon-192.png  ← 앱 아이콘 (소)
- icon-512.png  ← 앱 아이콘 (대)

## ✨ 기능 요약
- 🎯 자동모드: 버튼 하나로 번호 생성
- ⚡ 반자동모드: 고정번호 지정 후 나머지 자동 채움
- ✏️ 수동모드: 직접 6개 번호 선택
- 🚫 제외번호: 원하지 않는 번호 제거
- 📋 복사 기능: 생성된 번호 클립보드 복사
- 📵 오프라인: 인터넷 없어도 동작
