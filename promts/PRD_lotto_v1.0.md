# 로또 번호 생성기 PRD

> **Product Requirements Document v1.0**  
> 제외번호 선택 · 추천번호 생성 · 수동/반자동 모드  
> 작성일: 2025년 6월 | 상태: 초안(Draft) | 플랫폼: 웹 (Vanilla JS)

---

## 1. 프로젝트 개요

### 1.1 제품 목적

사용자가 로또 번호를 직접 선택(수동)하거나, 일부 번호만 고정하고 나머지를 자동으로 채우는(반자동) 방식으로 번호를 생성할 수 있는 웹 기반 도구입니다.  
제외하고 싶은 번호를 미리 지정하면 해당 번호를 빼고 추천 번호를 뽑아줍니다.

### 1.2 핵심 가치 제안

- 설치 없이 브라우저에서 즉시 사용 가능 (순수 바닐라 HTML/CSS/JS)
- 제외번호 설정으로 원하지 않는 번호를 사전에 필터링
- 수동 / 반자동 두 가지 모드 지원으로 사용자 자유도 극대화
- 추천번호 클릭 한 번으로 6개 번호 즉시 출력

## 2. 사용자 시나리오 (User Stories)

| # | 역할 | 시나리오 | 완료 기준 |
|---|------|----------|-----------|
| US-01 | 일반 사용자 | 제외할 번호를 클릭해서 선택하고 싶다 | 선택된 번호는 시각적으로 표시되고 추천 시 제외됨 |
| US-02 | 일반 사용자 | 고정하고 싶은 번호를 지정한 뒤 나머지 번호만 자동으로 채워 넣고 싶다 | 고정 번호 + 자동 채움으로 6개 번호가 완성됨 |
| US-03 | 일반 사용자 | 추천번호 버튼을 클릭하면 6개 번호가 바로 나왔으면 좋겠다 | 클릭 즉시 번호 6개가 로또 공 형태로 화면에 출력됨 |
| US-04 | 일반 사용자 | 6개 번호를 여러 게임으로 한꺼번에 뽑고 싶다 | 1~5게임 선택 후 각 게임의 번호가 한 번에 출력됨 |
| US-05 | 일반 사용자 | 생성된 번호를 복사하거나 초기화하고 싶다 | 번호 복사 버튼 및 전체 초기화 버튼이 동작함 |

## 3. 기능 요구사항 (Functional Requirements)

### 3.1 제외번호 선택 패널

- 1~45 번호가 격자(Grid) 형태로 모두 표시됨
- 번호를 클릭하면 '제외' 상태로 토글 (색상 변경으로 구분)
- 제외된 번호는 추천번호 생성 시 풀(Pool)에서 제거됨
- 제외번호 개수는 최대 39개로 제한 (최소 6개 풀 보장)
- 제외번호 전체 해제 버튼 제공

### 3.2 수동 모드 (Manual Mode)

- 사용자가 1~45 중에서 직접 6개 번호를 클릭하여 선택
- 6개 초과 선택 시 경고 메시지 표시
- 선택 완료 후 '번호 확정' 버튼 클릭 시 결과 출력
- 제외번호로 지정된 번호는 선택 불가 (비활성화 처리)

### 3.3 반자동 모드 (Semi-Auto Mode)

- 사용자가 1~5개의 번호를 '고정번호'로 선택
- 나머지 번호(6 - 고정번호 수)는 남은 풀에서 자동으로 무작위 선택
- 고정번호는 제외번호 풀에 없어야 함 (교차 선택 방지)
- '추천번호 생성' 버튼 클릭 시 즉시 결과 출력

### 3.4 추천번호 생성 (Auto Mode)

- '추천번호' 버튼 클릭 1회로 6개 번호를 완전 자동 생성
- 제외번호를 뺀 나머지 풀에서 무작위 추출 (Math.random 기반)
- 게임 수 선택 (1~5게임) 후 한 번에 여러 게임 출력 가능
- 번호는 오름차순으로 정렬하여 표시

### 3.5 결과 출력 영역

- 번호는 실제 로또 공(Ball) 스타일로 원형 디자인으로 표시
- 번호 구간별 색상 구분:
  - 1~10: 노란색
  - 11~20: 파란색
  - 21~30: 빨간색(핑크)
  - 31~40: 보라색
  - 41~45: 초록색
- 게임별 결과가 행(Row)으로 구분되어 출력됨
- 번호 복사 버튼: 텍스트 형태로 클립보드에 복사
- 전체 초기화 버튼: 제외번호, 고정번호, 결과 모두 리셋

## 6. 핵심 로직 명세

### 6.1 번호 생성 알고리즘

```
전체 풀 = [1~45] - 제외번호
```

- **수동 모드**: 사용자가 직접 6개 선택 → 확정 버튼 → 출력
- **반자동 모드**: 고정번호 + (전체 풀 - 고정번호)에서 랜덤 (6 - 고정수)개 추출
- **자동 모드**: 전체 풀에서 랜덤 6개 추출 (Fisher-Yates 셔플 후 앞 6개)
- 결과는 항상 오름차순 정렬 후 출력

### 6.2 유효성 검증 규칙

- 풀 크기 < 6 → `"제외번호가 너무 많습니다"` 경고
- 고정번호가 제외번호와 중복 → `"제외번호와 겹칩니다"` 경고
- 수동 모드 6개 미선택 시 확정 버튼 비활성화

## 8. 용어 정의 (Glossary)

| 용어 | 정의 |
|------|------|
| 제외번호 | 추천번호 풀에서 제거할 번호. 사용자가 사전에 지정 |
| 고정번호 | 반자동 모드에서 사용자가 직접 지정하는 번호. 결과에 반드시 포함됨 |
| 번호 풀 (Pool) | 제외번호를 뺀 후 실제 추첨 대상이 되는 번호 집합 |
| 수동 모드 | 사용자가 직접 6개 번호를 모두 선택하는 방식 |
| 반자동 모드 | 고정번호 지정 후 나머지를 자동 채움하는 방식 |
| 자동 모드 | 제약 없이 추천번호 버튼 하나로 6개 완전 자동 생성 |
| MVP | Minimum Viable Product. 최소 기능 제품 (필수 기능만 포함) |
